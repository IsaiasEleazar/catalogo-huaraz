# 🚀 Tienda de Tecnología Huaraz - Frontend con React (Semana 11)

Este proyecto corresponde al entregable práctico del curso **Fullstack Developer Software** (V Semestre) en **SENATI – CFP Huaraz**. Consiste en la migración de un sitio web tradicional hacia una **Single-Page Application (SPA)** moderna, reactiva y optimizada para dispositivos móviles utilizando **React** y **Vite**.

## 🎯 Objetivos Completados (Lista de Cotejo)
- [x] Inicialización y estructuración limpia del entorno con Vite.
- [x] Arquitectura de componentes modulares y reutilizables.
- [x] Transmisión fluida de datos de solo lectura a través de `Props`.
- [x] Lógica declarativa para búsquedas y filtrado dinámico por categorías mediante `useState`.
- [x] Sistema de navegación interna instantánea sin recargas al servidor usando `react-router-dom` con rutas estáticas y dinámicas (`/productos/:id`).
- [x] Formulario de contacto seguro y robusto protegido por esquemas de validación estrictos con `Formik` y `Yup`.

## 🛠️ Tecnologías y Librerías Utilizadas
- **React 19** & **Vite 6** (Entorno de desarrollo ultra rápido)
- **React Router DOM** (Enrutamiento dinámico local)
- **Formik** (Manejo eficiente del estado del formulario)
- **Yup** (Validaciones de esquemas en tiempo real)
- **JavaScript (ES6+)** & **CSS Inline** (Estilos modulares)

## 💻 Instrucciones de Ejecución Local

1. Clonar este repositorio en tu máquina local:
   ```bash
   git clone <enlace-de-tu-repositorio-de-github>
   ```
2. Instalar todas las dependencias del proyecto listadas en el `package.json`:
   ```bash
   npm install
   ```
3. Iniciar el servidor de desarrollo local:
   ```bash
   npm run dev
   ```
4. Abrir en el navegador la dirección indicada por la consola (por defecto `http://localhost:5173/`).
